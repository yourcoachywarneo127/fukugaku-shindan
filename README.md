# 復学可能性診断 Webアプリ (Version 1.0)

保護者に安心感を与え、お子さんの「現在地」と「次の一歩」を可視化するためのスマホ対応Webアプリケーションです。

## 特徴
- **フレームワーク不使用**: HTML/CSS/JavaScript(ES6+)のみで動作するため、GitHub Pages等へそのまま公開可能。
- **安心を与えるUI/UX**: 30〜50代女性（不登校のお子さんを持つ保護者）をターゲットにした、やさしく温かみのあるカラーデザイン。
- **完全に分離されたデータ設計**: 質問・結果文・タイプ情報はJavaScript初心者でも簡単に編集可能。

## ディレクトリ構成
```text
/fukugaku-shindan
├── index.html       # アプリのメイン構造
├── style.css        # 全デザイン・レスポンシブスタイル
├── script.js        # 診断制御・スコア算出・アニメーション処理
├── /data
│   ├── questions.js # 質問データ・ランダムメッセージ設定
│   ├── results.js   # ロードマップ定義
│   └── types.js     # 診断タイプ別結果メッセージ設定
